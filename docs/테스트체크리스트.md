## 집계 방법

1. `cd backend` 에서 해당 Sprint 커밋으로 이동한다: `git switch --detach 74384b9` (Sprint 2) / `814de06` (Sprint 3) / `db06359` (Sprint 4). 끝나면 `git switch main`.
2. MySQL 컨테이너를 띄우고 `./gradlew test` 를 돌린다. 옛 커밋은 Flyway 버전이 낮으므로 테스트 DB 스키마 충돌이 나면 `docker compose down -v` 로 비우고 다시 띄운다.
3. `..\collect-test-results.ps1` 을 실행하면 모듈별 tests/failures/errors/skipped 표와 "표에 붙일 값" 이 나온다. 그 값을 그대로 옮긴다.
4. 세 커밋을 다 돌리기 어려우면 **db06359 한 번만 돌리고** Sprint 2·3 행의 결과 칸에 "db06359 회귀로 대체" 라고 적는다. Sprint 별 건수를 옛 커밋에서 추측해 적지 않는다.
