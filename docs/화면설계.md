## 1. 화면 목록

> UI-10의 예약 신청은 UI-05 상세 화면 내 모달로 처리합니다.
UI-12(티켓/QR)는 UI-11 예약 내역 페이지 내에서 인라인으로 확인합니다(별도 페이지 없음).
QR 티켓은 결제 완료 후 비동기 발급되며, 발급 전에는 “발급 중” 상태를 표시합니다.
UI-07 박람회 등록/수정에 AI 소개글 초안 기능이 통합되어 있습니다.
>

## 3. 화면별 간단 기록

| 화면 | Actor·행동 | 입력 | 성공 표시 | 실패 표시·다음 행동 | 호출 계약 |
| --- | --- | --- | --- | --- | --- |
| **UI-01** 홈 / 메인 | 전체 — 진입 시 자동 로드 | 카테고리 칩·정렬 선택(선택) | VIP 캐러셀(없으면 기본 히어로만) + AI 추천 띠(로그인 시) + 박람회 카드 그리드 | 로드 실패 → “불러올 수 없습니다” + 새로고침 버튼 / 검색 결과 없음 → “조건에 맞는 박람회가 없습니다” | `listPublishedExpos`, `getActivePromotions`, `getRecommendations` (로그인), `getBulkTags` |
| **UI-02** 로그인 / 회원가입 | GUEST — 폼 입력 또는 소셜 버튼 클릭 | 회원가입: 이름·이메일·비밀번호·확인 / 로그인: 이메일·비밀번호 / 소셜: 팝업 인증 | 회원가입 → 관심사 선택 단계 전환 → 자동 로그인 → 홈 이동 / 로그인·소셜 → 이전 페이지 이동 | 400 이메일 중복·Validation 실패 → 인라인 오류 / 401 “이메일 또는 비밀번호가 올바르지 않습니다” / 소셜 401 SOCIAL_LOGIN_FAILED·503 제공자 장애 → 토스트 안내 | `signup`, `login`, `google`, `kakao`, `naver` |
| **UI-03** 관리자 페이지 | SUPER_ADMIN — 탭 전환·[승인]/[거절] 클릭 | 거절 시 거절 사유(선택) | 승인 200 → ORGANIZER 역할 부여·목록 갱신 / 정산 집계 숫자 표시 | 404 신청 없음·409 이미 처리됨 | `listOrganizerApplications`, `approveApplication`, `rejectApplication`, `getSettlement` |
| **UI-04** AI 자연어 검색 | 전체 — GNB 검색창에 자연어 입력 | 자연어 문장 (예: “다음 주말 서울 IT 행사”) | AI 해석 칩(지역·카테고리·날짜·유무료) + 결과 카드. `aiApplied=false` 면 “해석하지 못해 그대로 찾았습니다” 안내 | AI 예산 소진 → fallback 목록 (칩 없이) / 날짜 조건 있는데 503 → “날짜 조건을 확인하지 못했습니다” | `searchExpos` |
| **UI-05** 박람회 상세 | 전체 — 카드 클릭 진입 | 없음 | 박람회 정보 + 회차 카드(잔여정원·[예약하기]) / 잔여정원 0 → “마감” 비활성 | 404 → “존재하지 않는 박람회” 홈 이동 버튼 / 회차 로드 실패 → 기본 정보는 표시, 회차만 “조회 실패” | `getExpo`, `recordView` |
| **UI-06** 채널 등록 | ORGANIZER — [채널 만들기] 클릭 | 채널명(필수)·설명(선택)·로고(선택) | 201 → 채널 대시보드 이동 “채널 생성 완료” | 409 채널 이미 보유 / 400 채널명 중복 | `createChannel` |
